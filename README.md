# GophProfile

Учебный проект Яндекс.Практикума.

## Быстрый старт

```bash
# Поднять Postgres для локальной разработки
docker compose up -d

# Скопировать пример конфигурации
cp .env.example .env

# Запустить сервер
make run
```

## Команды

| Команда      | Описание                          |
|--------------|-----------------------------------|
| `make run`   | Запуск сервера                    |
| `make test`  | Запуск тестов                     |
| `make lint`  | Запуск golangci-lint              |
| `make build` | Сборка бинарника в `bin/server`   |
| `make clean` | Удаление собранных бинарников     |
