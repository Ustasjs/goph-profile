Pods and autoscaling:
  kubectl -n {{ .Release.Namespace }} get pods,hpa

{{- if .Values.migrations.enabled }}

Migrations run as a post-install/pre-upgrade hook Job; on the very
first install the app may answer 500 for a few seconds until the Job
finishes. Check it with:
  kubectl -n {{ .Release.Namespace }} logs job/{{ include "gophprofile.fullname" . }}-migrate
(the Job is deleted automatically once it succeeds)
{{- end }}
